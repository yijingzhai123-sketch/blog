# 机器学习核心概念：监督学习、无监督学习与强化学习

## 什么是机器学习？

机器学习（Machine Learning）是AI的核心分支，它的本质是：**让计算机从数据中自动学习规律，而不需要显式地编写规则**。

> 传统编程：输入 + 规则 → 输出
> 机器学习：输入 + 输出 → 规则（模型）

## 机器学习三大范式

```
                  ┌─────────────────────────────┐
                  │       机器学习三大范式         │
                  ├─────────────┬───────────────┤
                  │ 监督学习     │ 无监督学习      │
                  │ (有标签)     │ (无标签)        │
                  ├─────────────┴───────────────┤
                  │       强化学习 (试错学习)      │
                  └─────────────────────────────┘
```

---

## 一、监督学习（Supervised Learning）

### 核心思想

监督学习就像**有标准答案的练习题**。给模型输入数据和对应的正确答案，让模型学会从输入预测输出。

### 两大任务类型

#### 分类（Classification）
预测**离散的类别标签**。

| 应用场景 | 输入 | 输出 |
|----------|------|------|
| 垃圾邮件检测 | 邮件内容 | 是/否垃圾邮件 |
| 图像识别 | 图片像素 | 猫/狗/鸟... |
| 情感分析 | 用户评论 | 正面/负面/中性 |

#### 回归（Regression）
预测**连续的数值**。

| 应用场景 | 输入 | 输出 |
|----------|------|------|
| 房价预测 | 房屋特征 | 价格（如500万） |
| 股票预测 | 历史数据 | 未来股价 |
| 温度预测 | 气象数据 | 明日温度 |

### 常用算法
- **线性回归**：最简单的回归方法
- **逻辑回归**：二元分类的经典方法
- **决策树 & 随机森林**：直观易解释
- **支持向量机（SVM）**：适合高维数据
- **神经网络**：适合复杂模式识别

---

## 二、无监督学习（Unsupervised Learning）

### 核心思想

无监督学习面对的是**没有标准答案的数据**。模型的任务是自行发现数据中的隐藏结构和模式。

### 主要任务类型

#### 聚类（Clustering）
将相似的数据点归为一组：

- 用户分群（客户画像）
- 文档主题归类
- 图像分割
- 异常检测

#### 降维（Dimensionality Reduction）
在保留关键信息的前提下减少特征数量：

- 数据可视化（如 t-SNE）
- 去除噪声和冗余
- 特征提取与压缩

### 常用算法
- **K-Means**：最经典的聚类算法
- **DBSCAN**：基于密度的聚类
- **PCA（主成分分析）**：最常用的降维方法
- **自编码器（Autoencoder）**：用神经网络做降维

---

## 三、强化学习（Reinforcement Learning）

### 核心思想

强化学习模拟的是**试错学习**的过程。智能体（Agent）在环境（Environment）中执行动作（Action），获得奖励（Reward），目标是最大化累计奖励。

```python
# 强化学习的基本循环（伪代码）
state = env.reset()
while not done:
    action = agent.choose_action(state)   # 智能体选择动作
    next_state, reward, done = env.step(action)  # 执行并获得反馈
    agent.learn(state, action, reward, next_state)  # 从经验中学习
    state = next_state
```

### 关键概念

- **探索 vs 利用**：尝试新动作（探索）还是选择已知最优动作（利用）
- **马尔可夫决策过程（MDP）**：强化学习的数学框架
- **Q-learning**：学习每个状态-动作对的价值

### 经典应用
- AlphaGo下围棋
- 游戏AI（如Atari游戏、Dota2）
- 机器人控制
- 推荐系统优化

---

## 如何选择合适的方法？

| 场景 | 推荐方法 |
|------|----------|
| 有标注数据，需预测类别 | 监督学习-分类 |
| 有标注数据，需预测数值 | 监督学习-回归 |
| 无标注数据，需发现分组 | 无监督学习-聚类 |
| 无标注数据，需压缩维度 | 无监督学习-降维 |
| 序贯决策，优化长期回报 | 强化学习 |

## 总结

理解机器学习三大范式是掌握AI知识体系的第一步。简单记住：

- **监督学习** = 有答案的练习册 📚
- **无监督学习** = 没有答案，自己找规律 🔍
- **强化学习** = 玩游戏，做得好有奖励 🎮
